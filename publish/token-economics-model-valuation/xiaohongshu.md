## 笔记 1

封面字：

AI 公司估值
本质是在定价 token

封面图：

`/Users/wangye/workspace/blog/static/images/posts/token-economics-model-valuation/xhs-note-01-cover.png`

正文：

黄仁勋在 GTC 2026 说了一句话，我觉得是今年最重要的框架：

「数据中心是 token 工厂，token 是新的商品。」

如果这句话成立，AI 公司的估值逻辑就变得非常清楚：

公司价值 = token 产能 × token 质量（定价权）× 市场份额

先说 token 不是赢家通吃的。

市场上的 token 会分层，就像石油有轻重质之分。价格大概是这样的区间：普通应用层约 3 美元/百万 token，质量敏感任务约 6 美元，企业推理约 45 美元，最强模型实时推理约 150 美元。

一个用户可能同时用便宜模型处理杂活，用高级模型做关键判断。不同公司占不同价格带。

这就解释了为什么大厂估值和小公司估值差这么多。

以 Kimi 为例：3 个月从 43 亿美元涨到 180 亿美元。同期腾讯 AI 的市场溢价几乎为零。

原因不是腾讯没算力。腾讯算力远超 Kimi。

原因是：算力投入不等于产出高质量 token。

大厂模型团队服务太多内部业务，目标分散；决策链条长，迭代慢；顶尖人才留不住。同样的算力，产出的可能是低价 token。

Kimi 人才密度高、组织扁平，同样的算力产出高价 token，定价权更高，估值自然更高。

这也是 AI 公司估值里最容易被误解的一点：

买的不是算力，是 token 质量。

所以真正值得问的问题不是「这家公司有多少 GPU」，而是：

你的 token 到底有没有人持续买单？别人为什么不能用更便宜的 token 来替代你？

用这个框架倒推一下终局估值（2028-2030，仅为研究参考）：

OpenAI 推理市场 25-30% 份额，年收入约 600-750 亿美元，终局市值约 1.5-2 万亿美元。

Anthropic 15-20% 份额，年收入约 350-500 亿美元，终局市值约 8000 亿-1.2 万亿美元。

字节/豆包 5-8% 份额，终局市值约 1-1.5 万亿美元（含非 AI 业务）。

Kimi 3-5% 份额，终局市值约 1500-2500 亿美元。

腾讯 vs Meta 现在的估值差距是 2.5 倍，这说明中国科技公司的 AI 溢价几乎还没有被市场定价进去。

## 笔记 2

标题候选：
- 未来工程师的薪酬第四件套：token 预算
- token 越便宜，高手的账单应该越来越高
- 为什么 AI 用得越多，花的钱反而越多？

封面字：

工资 奖金 期权
还有 token 预算

封面图：

`/Users/wangye/workspace/blog/static/images/posts/token-economics-model-valuation/xhs-note-02-cover.png`

正文：

黄仁勋在 2026 年 3 月说了一件很有意思的事：

一个年薪 50 万美元的工程师，年 token 消耗应该达到 25 万美元——否则说明 AI 还没被真正用起来。

Reddit 上有人把这比作「哥伦比亚毒贩声称，如果你每年不花 10 万美元买可卡因，那你肯定有什么问题」，这条评论拿了 3000 多赞。

这个梗背后是真实的焦虑：token 消耗量正在成为衡量一家公司 AI 化程度的硬指标。

背后的逻辑其实很直接。

如果一个工程师年薪很高，却几乎不用 AI，不让 Agent 替自己跑任务——那公司没有真正把 AI 用起来，这个人的产出也没有被放大。

以前看工程师资源配置，看：工资、奖金、期权。

以后可能还要看：你每年能消耗多少高质量 token。

这里有一个反直觉的地方：

token 单价在降，但高水平工程师的 token 账单应该在涨。

单价三年降了 1000 倍，但这不是让总支出下降，而是让使用场景爆炸。

这就是 Jevons 悖论：单位成本越低，总消耗反而越高。

当 token 变便宜：
写代码前先让 AI 跑几种方案对比，值了。
提交前让 AI 做完整 review，值了。
调研时让 Agent 长时间检索归纳，值了。
维护项目时让 AI 持续读日志找异常，值了。

便宜的是单价，不是总量。高手会把省下来的钱用在更多场景上。

数据印证了这一点：Google 月处理 token 从 480 万亿涨到 980 万亿，半年翻倍。Microsoft Foundry API 年处理 500 万亿以上 token，同比 7 倍。Agent 工作流一个任务调用模型 10-20 次，7×24 不停跑。

所以以后判断一个团队的 AI 化程度，不能只问「你们有没有接入 AI」。

更应该问：哪些工作流已经变成 7×24 的 token 消耗？谁在定义 AI 该做什么，谁只是被 AI 替代执行？

被替代的是执行者。稀缺的是定义任务的人。

token 预算，是这个时代最直接的代理指标。

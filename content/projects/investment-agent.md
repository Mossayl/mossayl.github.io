## 背景

它是知识流水线最完整的一个下游。持续流入的行业与公司信息，在这里被转化成结构化的投资研究——这套系统验证了"不停收藏 → 流转 → 快速学习"能否真的让人在一个陌生领域快速变专业。

## 系统设计

契约化设计的多 workflow 投资研究系统：

- **个股分析 / 估值预测 / 买入时机判断**：各自独立的 workflow，有明确输入、输出、幂等规则和失败状态。
- **AI 基础建设三级产业链图谱**：从上游到下游的结构化梳理，支撑自上而下的研究。
- **全链路分离、可复现**：数据采集 → 研究 → 决策记录 → 静态站发布，各层职责清晰、不互相污染。

## 结果

在系统辅助下完成多笔真实投资决策。比起结果本身，更重要的是它证明了一件事：**一套设计良好的 agent 系统，能把个人从零到专业的学习周期显著压缩。**

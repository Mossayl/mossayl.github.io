**状态：核心 · 日常运行中**

## 问题

信息收藏即遗忘、散落各处。看到一条有价值的链接、一张图、一段话，收藏完就再也找不到，更谈不上转化成产出。我想要的不是又一个收藏夹，而是一条能自己跑的流水线——让信息进来之后，自动流向它该去的地方。

## 系统设计

基于飞书搭建 collect → process → consume → output 四层流水线：

- **collect（采集）**：转发任意链接 / 图片 / 文字到飞书，即触发。自然语言就是入口。
- **process（处理）**：agent 自动完成爬取、解析、标准化、打标、路由。
- **consume（消费）**：按主题分发给写作、投资、评测、harness 跟踪四类下游。
- **output（产出）**：沉淀为可直接调用的素材，支撑文章撰写、投资研究等。

## 为什么它重要

它是我所有对外产出的**上游引擎**：已发布的多篇公众号文章、个人投资系统的研究素材、以及我对 agent / harness 的 know-how，都由这条流水线"持续收藏 → 自动流转 → 快速学习"沉淀而来。

它本质上是一个跑在我自己身上的 personal harness——把"信息进来"到"产出去"之间原本靠大脑手动搬运的过程，拆成 agent 可自动执行的环节。这也是我理解 agent / harness 不靠读论文、而靠亲手构建的原因。
